# Issue and PR labels

The label taxonomy used on the tracker. Colors and descriptions are set once in
repository settings by a maintainer; this file is the canonical description.

## Type

| Label | Meaning |
|-------|---------|
| `enhancement` | a new feature or capability |
| `documentation` | docs, examples, or explanatory content |
| `refactor` | internal restructuring, no behavior change |
| `investigation` | open question to resolve before implementation |
| `testing` | test coverage or conformance work |

## Area

| Label | Meaning |
|-------|---------|
| `security` | threat model, gate, signing, untrusted input |
| `reliability` | correctness and failure handling |
| `performance` | speed / memory |
| `developer-experience` | CLI, diagnostics, authoring workflow |
| `architecture` | cross-cutting design decisions |
| `integration` / `integrations` | external tools, frameworks, CI |
| `ecosystem` | distribution, packaging, adjacent projects |
| `adoption` | onboarding, docs site, demos |
| `llm` / `ai` | model-facing behavior, judges |
| `product` | user-facing language/runtime capability |

## Priority

`priority: high`, `priority: medium`, `priority: low` — relative urgency.

## Complexity

`complexity:simple`, `complexity:average`, `complexity:complex` — a rough size
signal for contributors picking work.

## Contributor entry points

| Label | Meaning |
|-------|---------|
| `good first issue` | scoped to start without maintainer help |
| `good-first-ai-issue` | well-specified enough for an AI coding agent |
| `help wanted` | maintainer would welcome a contributor here |

## Status / flags

| Label | Meaning |
|-------|---------|
| `roadmap` | tracked on the roadmap ([ROADMAP.md](../ROADMAP.md)) |
| `flagship` | a headline capability |
| `blocked` | waiting on another issue (named in a comment) |
| `breaking-change` | changes public behavior/API |
| `deprecation` | removes or sunsets something |

Picking your first issue? Filter by
[`good first issue`](https://github.com/dgenio/intentflow/labels/good%20first%20issue)
and see [CONTRIBUTING.md](../CONTRIBUTING.md).
