# Community

## Where things go

- **Questions, ideas, "how would I model X?"** → [Discussions](https://github.com/dgenio/intentflow/discussions).
- **Confirmed defects and scoped work** → [Issues](https://github.com/dgenio/intentflow/issues).
- **Show off a governed program you built** → the **Show and tell** category in
  Discussions.
- **Security vulnerabilities** → private disclosure, see [SECURITY.md](../SECURITY.md).

## Discussion categories

When Discussions is enabled (see [maintainer-setup.md](maintainer-setup.md)),
the categories are:

- **Announcements** — maintainer posts (releases, direction).
- **Q&A** — answerable questions about using IntentFlow.
- **Ideas** — pre-issue design talk (language evolution, new predicates).
- **Show and tell** — your `.iflow` programs. A suggested share format: the goal
  source, a one-line description of the domain, and optionally a redacted
  witness.

## Suggested seed threads

To avoid an empty tab, seed these when enabling Discussions:

1. **Welcome & where things go** (Announcements) — the routing above.
2. **What are you governing?** (Show and tell) — invite programs.
3. **Language evolution: imports and multi-file programs** (Ideas) — a live
   design question to model the category.
